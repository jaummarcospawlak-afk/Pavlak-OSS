# Código de conduta

O projeto recebe contribuições técnicas de pessoas com experiências diferentes. Esperamos comunicação respeitosa, objetiva e sem ataques pessoais, discriminação, assédio, exposição de dados privados ou pressão para contornar permissões.

Discussões devem se concentrar no código, na evidência reproduzível e no impacto para as pessoas usuárias. Uma discordância sobre arquitetura é bem-vinda; uma acusação sobre caráter não é.

Problemas de conduta devem ser encaminhados em privado ao mantenedor por um canal seguro. Não publique dados pessoais, credenciais ou material jurídico para sustentar uma reclamação.
