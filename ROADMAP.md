# Roadmap

O roadmap é uma lista de trabalho, não uma lista de funcionalidades entregues.

## Próximo ciclo — confiabilidade pública

- escolher e adicionar a licença oficial;
- criar ou conectar o histórico Git canônico e confirmar o destino público;
- separar uma suíte de fixtures sintéticas do material privado;
- corrigir ou isolar os 16 testes que falharam no ambiente atual;
- documentar um build iOS reproduzível sem identidade de assinatura do autor;
- fechar uma matriz de aceitação manual para busca, OCR, Spotlight e pareamento.

## Ciclo seguinte — consolidação

- escolher um runtime canônico entre o pacote principal e `PavlakUnifiedCore`;
- unificar o histórico de seleção, busca local, Link e perguntas contextuais;
- medir ranking textual contra uma alternativa semântica em corpus sintético;
- transformar resultados de conectores em estados verificáveis, não apenas cartões de abertura;
- adicionar validação automatizada de vazamento de caminhos, segredos e dados privados.

## Exploração posterior

- App Intents para busca e abertura com semântica revalidada;
- relações entre documentos com evidência e incerteza explícitas;
- contribuições externas para novos formatos e provedores, atrás das mesmas políticas de autorização;
- distribuição assinada e documentação de instalação para pessoas externas.
