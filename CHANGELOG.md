# Changelog

## Snapshot público — candidato técnico

- documentação pública inicial para arquitetura, contribuição, segurança, roadmap e candidatura ao Codex Open Source Fund;
- README reorganizado para distinguir implementação, desenvolvimento e planejamento;
- `.gitignore` ampliado para excluir builds, backups, mídia, dumps de erro, relatórios privados e material de assinatura;
- identificador de equipe Apple removido do projeto compartilhado;
- nomes de fixtures de teste substituídos por valores sintéticos;
- templates iniciais de issue e pull request adicionados.

Este changelog descreve o snapshot público e sua preparação documental e de higiene. Não representa uma nova versão binária nem prova de aceitação do aplicativo.
